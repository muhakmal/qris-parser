# Security Policy

## Supported Versions

We release patches and security fixes for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

The **QRIS Parser** team takes security seriously. If you discover a security vulnerability, we appreciate your help in disclosing it to us responsibly.

### How to Report
- **Please DO NOT report security issues via public GitHub Issues.**
- Instead, report security advisories privately via [GitHub Private Vulnerability Reporting](https://github.com/muhakmal/qris-parser/security/advisories/new) or by sending an email to `muhakmal@users.noreply.github.com`.
- Include a detailed description of the vulnerability, steps to reproduce, sample payload, and potential impact.

### Response Timeline
- We will acknowledge receipt of your vulnerability report within **48 hours**.
- We will provide a status update or fix within **7 business days**.
- Once a fix is verified, a patch release and advisory credit will be published.
